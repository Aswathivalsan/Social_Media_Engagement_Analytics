# Social_Media_Engagement_Analytics
Assignment 
Social Media Engagement Analytics Using Python

Project Summary

Introduction

The project, Social Media Engagement Analytics Using Python, aims to analyze social media engagement data and understand user behavior and content performance.

Tools and Technologies

Python

Google Colab

Pandas

NumPy

Matplotlib

Seaborn

Plotly

Data Cleaning

Missing values were identified and handled using appropriate methods. Duplicate records were removed, incorrect data types were corrected, categorical values were standardized, and hashtag counts were extracted.

Data Analysis

Exploratory Data Analysis was performed to understand the dataset. Statistical measures such as mean, median, mode, standard deviation, variance and percentiles were calculated.

Data Visualization

Different visualizations were created to understand engagement patterns, including scatter plots, line charts, bar charts, pie charts, histograms, box plots, heatmaps and interactive charts.
